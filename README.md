📚 EdVyro Library Manager

Project Description

EdVyro Library Manager is a beginner-friendly C++ console application that helps manage library operations. It uses Object-Oriented Programming concepts such as classes, encapsulation, collections, and file handling.

Features

- Add new books to the library.
- Register library members.
- Display all available books.
- Search for books.
- Issue books to members.
- Return issued books.
- Track book availability.
- Store library records in a local file.
- Reload saved records when the application starts.

Technologies Used

- Programming Language: C++
- Concepts: Object-Oriented Programming (OOP)
- Data Storage: File Handling
- IDE: Visual Studio Code

How to Run

1. Compile the program

2. Run the application on Windows
